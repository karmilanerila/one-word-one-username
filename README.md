The entry is a single word: "karmilanerila", the entrant's own make.fun handle. It is Karmila's real name, worn as her username — a warm, human name among joke handles, memorable on one read, and proudly hers. No spaces, no padding, no gloss: just the name itself, written as the whole entry.

## Run it

```sh
python3 main.py
```

This writes `entry.txt` (13 bytes, no trailing newline) into the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).
